# VEDA Technology — Task 6: Excel Formulas & Functions Fundamentals

## Project Overview
This project demonstrates essential Microsoft Excel formulas and functions used in everyday data analysis. It was completed as part of VEDA Technology's internship task series.

## Objectives
- Practice lookup functions to retrieve information from transactional data.
- Apply logical functions to classify records.
- Use conditional aggregation and counting functions.
- Clean and combine text using Excel text functions.
- Document formula syntax, practical applications, and interview concepts.

## Workbook Structure
The workbook contains three worksheets:

1. **Sales_Data:** Transactional sales dataset used for formula practice.
2. **Formula_Practice:** Practical formula examples, inputs, calculated results, and purposes.
3. **Formula_Guide:** Formula explanations, use cases, and key Excel interview concepts.

## Functions Covered
- VLOOKUP
- XLOOKUP
- IF
- SUMIFS
- COUNTIFS
- LEFT
- RIGHT
- TRIM
- PROPER
- TEXTJOIN

## Key Learnings
- Retrieving values using lookup functions.
- Applying logical conditions to classify data.
- Summarizing and counting records using multiple criteria.
- Cleaning text and standardizing names.
- Combining text fields into meaningful outputs.

## Tools Used
- Microsoft Excel
- Excel formulas and structured table references
